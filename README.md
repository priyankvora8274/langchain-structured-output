# LangChain Structured Output

A collection of Python examples demonstrating how to generate **structured LLM responses** using LangChain.

## 📌 Project Overview

Explore different approaches to extracting structured data from Large Language Models (LLMs) using LangChain's `with_structured_output()` method.

## 📂 Repository Structure

- **with_structured_output_json_schema/** – Format responses using JSON Schema.
- **with_structured_output_pydentic/** – Define and validate responses using Pydantic models.
- **with_structured_output_typed_dict/** – Structure responses using Python TypedDict.

## 🛠️ Tech Stack

Python · LangChain · Pydantic · JSON Schema · TypedDict

## 🚀 Getting Started

```bash
git clone https://github.com/priyankvora8274/langchain-structured-output.git
cd langchain-structured-output
pip install -r requirements.txt
```

Configure the required API keys as environment variables before running the examples.

## 🎯 Learning Objectives

Learn schema-based LLM output formatting, structured data extraction, and validation for reliable AI applications.
